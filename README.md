# Sports-in-One Rebuild

Private development copy of the public [Sports-in-One](https://github.com/SRchaudhari15/Sports-in-One) repository.

## Rebuild goals
- Preserve the original frontend and backend as a baseline.
- Remove exposed credentials and demo-only security shortcuts.
- Establish a single source of truth for schemas, configuration, and frontend.
- Add automated validation and complete real, persistent workflows incrementally.

## Security note
Do not place real passwords, JWT secrets, API keys, private user data, uploads, or production database credentials in source control. Use environment variables and a local ignored `.env` file.

This repository is a development copy, not a production-ready deployment. Features must be tested before being advertised as live.
